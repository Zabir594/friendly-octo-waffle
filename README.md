## Вариант Random Password Generator
## Описание проекта
Это графическое приложение (*GUI*), написанное на *Python*, предназначенное для генерации случайных паролей. Пользователь может гибко настраивать параметры пароля: выбирать его длину с помощью ползунка и указывать, какие типы символов использовать (цифры, буквы, спецсимволы).

Приложение сохраняет историю всех сгенерированных паролей в файл `history.json` для последующего использования. Также реализована функция копирования сгенерированного пароля в буфер обмена.

## Технологии
*   **Язык программирования:** *Python 3.x*.
*   **Библиотеки:** используются только стандартные библиотеки Python (`tkinter`, `random`, `json`), поэтому установка дополнительных модулей не требуется.
*   **Система контроля версий:** проект рекомендуется хранить в *Git*-репозитории (например, на *GitHub*).

## Инструкция по запуску
1.  Убедитесь, что на вашем компьютере установлен **Python 3**.
2.  Поместите файл `main.py` в папку.
3.  Откройте терминал или командную строку и перейдите в папку с файлом.
4.  Запустите приложение командой:
    ```bash
    python main.py
    ```
5.  После закрытия программы история паролей будет сохранена в файл `history.json` в той же директории.
